# Asset sources and review register

Every bundled third-party image must have a traceable source and a recorded review before it is published. Keeping an image in this repository does not itself establish a right to redistribute it.

## Required record

For each asset, record:

- Repository path
- Related internal media ID
- Asset type (logo, poster, backdrop, fallback)
- Original source URL and source identifier (for example, TMDB image path)
- Creator/rightsholder, when known
- Date retrieved
- License, permission or other documented basis for use
- Attribution text required, if any
- Review status: `pending`, `approved`, or `do-not-publish`
- Reviewer and review date

## Review policy

- Do not treat an accessible TMDB image path as blanket permission to redistribute the image.
- Check current TMDB API/image terms, attribution requirements and applicable third-party rights before bundling assets.
- Keep this file and the website attribution in sync with the actual assets and applicable requirements.
- Assets with unclear usage status must remain unpublished until reviewed.
- If a rights holder requests review/removal, open a private maintainer discussion where appropriate, pause distribution of the disputed asset and resolve it promptly.
