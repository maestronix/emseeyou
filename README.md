# EmSeeyou - MCU Watch Tracker

A beautiful, interactive timeline tracker for the Marvel Cinematic Universe with Trakt.tv integration.

## Features

- 📺 Track your MCU watch progress across movies and TV shows
- 🔄 Sync with Trakt.tv
- 🎨 Beautiful curved timeline visualization with phase separators
- 📊 Watch statistics and progress tracking
- 🌓 Dark mode optimized
- 📱 Responsive design

## Tech Stack

- Next.js 14
- React
- TypeScript
- Tailwind CSS
- Trakt.tv API
